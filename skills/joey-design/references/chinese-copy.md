# 中文成品怎么写

先看这句话写给谁、摆在哪里，再决定留几个字

| 位置 | 写法 | 例子 |
| --- | --- | --- |
| 演示标题 | 写出这一页要观众看到的东西，把补充资料留给备注 | 同一个音高，换种波形听听 |
| 图文封面 | 找出读者今天就能试的一步 | 等一个人走进那块光里 |
| 界面按钮 | 动词跟着对象走，需要导出文件时写清格式 | 下载询样单、加入课表 |
| 碰到问题 | 点名哪一步卡住，给一个能做的动作 | 和「活字排版」撞时了，先移出那堂再换课 |
| 数据说明 | 写清分母、时间和来源，数字和单位放在一起 | 410 次访问，31 条询盘 |

中文标题、图注、正文、按钮和演讲备注都不加句号，长句读起来憋气就拆段，问题保留问号
删掉“赋能”“一站式”“沉浸式体验”这类能换给任何项目的词
没有现场材料就写动作和事实，别补“我试过”、用户评价或漂亮数字
保留文件名、小数点、链接、代码和用户要求逐字照录的原文
客户给的图优先写能看见的细节，素材署名和示例数据的来历留在读者找得到的地方
